Photon

A file moves between two devices as light. One screen paints it, the other reads it with a camera. No network, no pairing, nothing to install.

Send Pick a file. This screen becomes the transmitter. Receive Point this camera at the other screen.

Each cell of the grid is one of eight colours, so it carries three bits where a black-and-white code carries one.

Every frame is an independent combination of the file's blocks, so the receiver needs enough frames rather than particular ones. There is nothing to retransmit and nothing to ask for — a camera pointed at a screen has no way to reply.

The file is cut into windows, written out one at a time, so memory does not grow with file size. The sender loops; a window you missed comes back round.
