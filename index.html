Photon

Move a file between two devices using nothing but a screen and a camera. No network, no pairing, no app.

Send →Pick a file. This screen becomes the transmitter. Receive →Point this camera at the other screen.

How it works

The sender paints the file as an endless run of colour grids. Each cell is one of eight saturated colours, so it carries three bits rather than the one a black-and-white QR module manages.

Every frame is an independent fountain-coded combination of the file's blocks. The receiver needs enough frames, not specific ones, so there is no handshake and nothing to retransmit — which is just as well, because a camera pointed at a screen has no way to ask.

The file is cut into windows that are decoded and written out one at a time, so memory does not grow with file size. The sender loops forever; a window you missed comes back round.
